# GeoAPI — ქართული ტექსტების აუდიტი

თარიღი: 2026-10-18

ეს არის ტექსტის გამართვის ანგარიში. API-ის მისამართები, HTTP მეთოდები, JSON ველები, გასაღების ფორმატი, ავტორიზაცია, ბაზის სქემა და ვიჯეტის კონტრაქტი არ შეცვლილა.

## რა შეიცვალა

მომხმარებლისთვის ხილული ტექსტები გასწორდა ერთიანი ტერმინებით: ბრენდი, მოდელი, თაობა, გამოშვების წელი, ძარის ტიპი, საჯარო API გასაღები, საიდუმლო API გასაღები, ვიჯეტი, მოთხოვნა, პასუხი, მოთხოვნების სიხშირის ლიმიტი, თვიური მოთხოვნების ლიმიტი, დოკუმენტაცია, ინტეგრაცია.

### მთავარი გვერდი

- SEO სათაური: `GeoAPI — ავტომობილების კატალოგი, API და მზა ვიჯეტი`
- აღწერა, H1, ორი ღილაკი და დემოს ტექსტი დავალების ფორმულირებით
- დემოს ველები: აირჩიეთ ბრენდი / მოდელი / წელი / ძარის ტიპი
- დამოკიდებული ველი აჩვენებს `ჯერ აირჩიეთ ბრენდი` და `ჯერ აირჩიეთ მოდელი`
- მაგალითის იარლიყი: `GET /api/v1/brands` (დემო თვითონ რამდენიმე POST-ს აკეთებს `/widget/v1/demo/...`-ზე)
- რაოდენობები დინამიკურია (`#counts`). ამ შემოწმებისას: 314 ბრენდი, 4 710 მოდელი, 10 228 თაობა
- ამოღებულია „ერთი მოთხოვნით“ და არასრული `GET /v1`

### რეგისტრაცია, შესვლა, პაროლი

- სათაურები და სამი ნაბიჯი: ანგარიში, შემდეგ პროექტი და გასაღები, შემდეგ ინტეგრაცია
- ელფოსტის დადასტურება გასაღებს არ ქმნის. ეს პირდაპირ წერია
- კონფიდენციალურობის ტექსტი და გამოყენების წესების მოსანიშნი ველი ცალ-ცალკეა. პოლიტიკის წაკითხვა თანხმობა არ არის
- პაროლის წესი უცვლელია: მინიმუმ 15, მაქსიმუმ 128 სიმბოლო. სირთულის მოთხოვნა არ დაემატა
- ლიმიტი ემთხვევა backend-ს: 60 მოთხოვნა წუთში და 10 000 წარმატებული მოთხოვნა კალენდარულ თვეში
- პაროლის აღდგენა ერთსა და იმავე ტექსტს აბრუნებს არსებულ და არარსებულ ელფოსტაზე

### დოკუმენტაცია

`/guide` მოიცავს დაწყებას, გასაღებებს, ლიმიტებს, ვიჯეტს, origin-ს, `carapi:change`-ს, Cursor / Claude Code / Codex-ს და ოთხ GET მეთოდს.

- სერვერული მაგალითი: `Authorization: Bearer <SERVER_API_KEY>`
- ვიჯეტის ნიმუში: `carapi_pk_example` და `https://geoapi.ge/widget/v1/carapi-filter.js`
- `generation_id` და `modification_id` ამ ვერსიაში ყოველთვის `null`-ია. მოდიფიკაციის არჩევა მხარდაჭერილი არ არის
- Cursor იყენებს `.cursor/rules/carapi.mdc`-ს `alwaysApply: true` frontmatter-ით. Claude Code კითხულობს `CLAUDE.md`-ს. Codex კითხულობს `AGENTS.md`-ს. სამივე ერთ ფაილს ერთნაირად არ კითხულობს
- `page` და `per_page` წერია მხოლოდ სიის მეთოდებზე. `GET /api/v1/coverage` მათ არ იყენებს
- 401: გასაღები არ არის, არასწორია, გაუქმებულია ან ვადაგასულია
- 403: წვდომის პირობა (ელფოსტა, პროექტის მდგომარეობა, scope, ვიჯეტის origin)
- 429: `RATE_LIMIT_EXCEEDED` ან `MONTHLY_QUOTA_EXCEEDED`, ორივეს აქვს `Retry-After`

### კაბინეტი და ვიჯეტი

- ნავიგაცია: პროექტის პარამეტრები, API გასაღებები, დაშვებული დომენები, მოხმარების სტატისტიკა, ვიჯეტის ჩასმა
- საიდუმლო გასაღები სრულად ერთხელ ჩანს
- დომენების შენახვა მთელ სიას ანაცვლებს. ღილაკია „ცვლილებების შენახვა“, არა „დომენის დამატება“
- Origin: ბილიკის და wildcard-ის გარეშე. `http` მხოლოდ `localhost` და `127.0.0.1`
- კაბინეტიდან კოპირებული ჩასმა აბსოლუტურ მისამართს იყენებს. ბილიკი უცვლელია
- ვიჯეტის წარწერები: გამოშვების წელი, ძარის ტიპი, აირჩიეთ…

## ტექნიკური უზუსტობები, რომლებიც გასწორდა

- დოკუმენტაცია აღარ ამბობს, რომ კატალოგი ერთი მოთხოვნით მოდის
- `GET /v1` შეიცვალა რეალური `GET /api/v1/brands`-ით
- აღარ წერია, რომ ელფოსტის დადასტურება გასაღებს ქმნის
- `modification_id` აღარ არის აღწერილი როგორც არჩევადი მოდიფიკაცია
- „ვიჯეტის სტილი“ გახდა „ვიჯეტის ჩასმა“. სტილის რედაქტორი არ არსებობს და არ დაემატა
- ფარდობითი widget URL კაბინეტში სხვა საიტზე არასწორ ჰოსტს ტვირთავდა. ახლა ჩასმა მიმდინარე ჰოსტის სრულ მისამართს იძლევა
- პაროლის ინდიკატორი აღარ მოითხოვს სიმბოლოებს, რომლებსაც ვალიდაცია არ ამოწმებს
- დოკუმენტაციის კოდის კოპირება მუშაობს იმ ბლოკზეც, სადაც ჩანართი არ არის

## შეცვლილი ფაილები

- `public/index.php` — მთავარი, დოკუმენტაცია, გამოყენების წესები, კონფიდენციალურობა, 404

- `src/Platform/Http.php` — ფორმის და წერილების ტექსტები
- `src/Platform/Passwords.php` — მხოლოდ შეტყობინების ტექსტი

- `tests/platform_auth_test.php`, `tests/email_reset_test.php`, `tests/projects_api_keys_test.php`, `tests/browser/site-flow.mjs` — ძველ ტექსტზე მიბმული შემოწმებები
