# პროექტები და სერვერული გასაღებები

production-ში სამივე დროშა ჩართულია. ვიჯეტი და კვოტა მუშაობს. გადახდა და ფოტოების API არ დაწყებულა.

## პროექტი

კაბინეტის განყოფილებაა „ჩემი პროექტები“. მომხმარებელი ქმნის პროექტს, ცვლის სახელს და `http`/`https` მისამართს, რთავს და თიშავს. მისამართი მხოლოდ აღწერაა: სერვერი მას არ ხსნის და დომენით გასაღებს არ ამოწმებს. მფლობელი მხოლოდ სესიიდან იღება. სხვისი პროექტი 404-ია. ყველა ცვლილება `POST`-ია CSRF-ით.

დაუდასტურებელ მომხმარებელს პროექტის შექმნა შეუძლია. გასაღების შექმნა და გამოყენება მოითხოვს `email_verified_at`-ს. წერილის გაგზავნა აგებულია. რეალური SMTP მიერთებულია. სამუშაო `carbase`-ში ანგარიშები ხელით არ შექმნილა.

## გასაღები

ფორმატი: `geoapi_sk_<selector>_<secret>`. `secret` არის `random_bytes(32)`-ის უსაფრთხო კოდი. ბაზაში ინახება `selector` და SHA-256 ჰეში. შედარება `hash_equals`-ით ხდება. Argon2id პაროლებზე უცვლელია.

სრული გასაღები მხოლოდ შექმნის პასუხში ჩანს, `Cache-Control: no-store`-ით და კოპირების ღილაკით. ტექსტი: „შეინახეთ გასაღები — სრულად ხელახლა აღარ გამოჩნდება“. სესიაში, `localStorage`-ში, ლოგში და URL-ში არ ინახება. სიაში ჩანს დაფარული იარლიყი. დაკარგვისას იქმნება ახალი და ძველი უქმდება `revoked_at`-ით. ერთ პროექტზე რამდენიმე გასაღები შეიძლება. ფიზიკური წაშლა არ არის. პროექტის ხელახლა ჩართვა გაუქმებულ გასაღებს არ აღადგენს.

სერვერული გასაღები ბრაუზერის სკრიპტში არ უნდა ჩაიდოს. ჩასასმელი ფილტრი საჯარო `geoapi_pk_` გასაღებს იყენებს: `docs/WIDGET_INTEGRATION.md`.

## კატალოგი

ოთხივე `GET /api/v1/...` მარშრუტი ითხოვს მხოლოდ სათაურს:

```http
Authorization: Bearer geoapi_sk_selector_secret
```

ეს placeholder-ია, რეალური გასაღები არა. Query string და cookie არ მიიღება. კაბინეტის სესია გასაღებს არ ცვლის. შემოწმება platform კავშირით მთავრდება კატალოგის `SELECT`-მდე. კატალოგს კითხულობს `geoapi_catalog_reader`.

| სტატუსი | შემთხვევა |
|---|---|
| 404 | კატალოგის დროშა გამორთულია, ბაზა არ იხსნება |
| 401 | გასაღები არ არის, არასწორია, გაუქმებულია ან ვადაგასულია. სათაური `WWW-Authenticate: Bearer` |
| 403 | გასაღები სწორია, მაგრამ პროექტი გამორთულია, მფლობელი შეჩერებულია ან ელფოსტა დაუდასტურებელია |
| 503 | platform ან catalog მიუწვდომელია |

`last_used_at` ახლდება წარმატებული მოთხოვნის შემდეგ, თითო გასაღებზე არა უმეტეს წუთში ერთხელ. დადებითი შედეგი არ ქეშდება. კვოტა და სტატისტიკა: `docs/USAGE_AND_LIMITS.md`.

მიგრაცია: `php bin/migrate.php` ადმინისტრაციული `GEOAPI_PLATFORM_ADMIN_*` ცვლადებით. ფაილი `migrations/002_projects_api_keys.sql` არსებულ `001`-ს არ ცვლის.
