# კატალოგის ლიმიტები და მოხმარება

production-ში დროშები ჩართულია. Redis არ დაემატა. აღრიცხვა PostgreSQL-შია, ინტერფეისი `UsageStore` / `UsageLimiter` ცალკეა.

საწყისი სატესტო პარამეტრები, არა კომერციული ტარიფი:

- პროექტი: 60 მოთხოვნა UTC წუთში
- პროექტი: 2 000 წარმატებული მოთხოვნა UTC დღეში (`platform.project_limits.per_day`, ნაგულისხმევი 2000)
- პროექტი: 10 000 წარმატებული მოთხოვნა UTC თვეში
- IP: 300 კატალოგის მოთხოვნა UTC წუთში (`CARAPI_IP_PER_MINUTE`)

სვეტის დამატებამდე დღიური ზღვარი არ მოწმდება. 429 კოდი დღისთვის არის `DAILY_QUOTA_EXCEEDED`. წარმატებულ პასუხზე `X-RateLimit-Limit`, `X-RateLimit-Remaining` და `X-RateLimit-Reset` წუთის ფანჯარაა. `X-Quota-*` კვლავ თვის კვოტაა.

ფანჯარა ფიქსირებული კალენდარული წუთია, არა მოძრავი 60 წამი. თვე UTC კალენდარული თვეა. ახალი თვე ახალ ჩანაწერს იწყებს.

ერთეულია ოთხივე კატალოგის მარშრუტისა და ვიჯეტის სამი მარშრუტის HTTP 200, ცარიელი სიის ჩათვლით. ვიჯეტი და სერვერული API ერთ პროექტზე საერთო მრიცხველს ხარჯავს. თითო გვერდი ცალკე ერთეულია. 401, 403, 404, 405, 422, 429, 503 და კაბინეტი თვიურ კვოტას არ ხარჯავს. წარუმატებელი მოთხოვნა მაინც ექვემდებარება წუთის ლიმიტს.

კვოტა პროექტისაა. ახალი გასაღები და პროექტის ჩართვა მრიცხველს არ ანულებს. ლიმიტი ბაზაშია. კაბინეტიდან გაზრდა არ შეიძლება. ჩანაწერის არქონა შეუზღუდავ წვდომას არ ნიშნავს.

IP არის უშუალო `REMOTE_ADDR`. `X-Forwarded-For` არ გამოიყენება.

წარმატებული პასუხის წინ მოკლე ტრანზაქცია ზრდის თვიურ და დღიურ მრიცხველს ერთად, მხოლოდ თუ კვოტა დარჩა. commit-ის შემდეგ იგზავნება 200. თუ პარალელურმა მოთხოვნამ ბოლო ერთეული აიღო, პასუხია 429 და მონაცემი არ იგზავნება. კატალოგის შეცდომა კვოტას არ ხარჯავს. აღრიცხვის შეცდომა 429-ის ნაცვლად 503-ია და დაუთვლელი 200 არ გაიცემა.

მოხმარება ფიქსირდება პასუხის მომზადებისას. კლიენტის კავშირის შემდგომი გაწყვეტა ამ ერთეულს უკან არ აბრუნებს. ხელახალი HTTP მოთხოვნა ცალკე ერთეულია.

429 კოდები: `RATE_LIMIT_EXCEEDED`, `MONTHLY_QUOTA_EXCEEDED`. სათაური `Retry-After`. წარმატებულ პასუხზეა `X-Quota-Limit`, `X-Quota-Remaining`, `X-Quota-Reset`. 401 კვოტას არ აჩვენებს.

კაბინეტის პროექტის გვერდი აჩვენებს თვის ლიმიტს, გამოყენებულს, დარჩენილს, განახლების დროს და დღიურ განაწილებას მარშრუტის მიხედვით. სხვისი პროექტი 404-ია. სტატისტიკის ნახვა კვოტას არ ხარჯავს.

ვადაგასული წუთის ფანჯრები: `php bin/purge-rate-windows.php` platform-ის გარემოს ცვლადებით.

ტესტი `tests/usage_limits_test.php` გავიდა, მათ შორის 6 პარალელური პროცესი: ერთი 200 და დანარჩენი 429, მრიცხველი 1. არსებული ოთხი ტესტიც გავიდა.
