# GeoAPI — დიზაინის აუდიტი

თარიღი: 2026-10-18  
წყარო: ამ რეპოზიტორიის მოქმედი კოდი. ცოცხალი HTTP მოთხოვნა, ბაზის რიცხვები და სერვერის გარემოს ცვლადები ამ სესიაში არ წაკითხულა.

სტატუსი ნიშნავს:

| სტატუსი | აზრი |
|---|---|
| მუშაობს | კოდში სრული გზაა და ფრონტ-კონტროლერთან არის მიბმული |
| ნაწილობრივ მუშაობს | გზა არსებობს, მაგრამ დროშაზე, არასრულ მონაცემზე ან ერთ გვერდზეა შეკრული |
| placeholder | ინტერფეისში ჩანს, მოქმედება არ აქვს |
| დაგეგმილია | კოდი პირდაპირ წერს, რომ ფუნქცია შემდეგ ეტაპზე დაემატება |
| უცნობია | კოდი არსებობს, მაგრამ ცოცხალი ჩართვა ან მონაცემი ამ სესიაში არ დამოწმებულა |

ახალი ვიზუალური მიმართულება (მხოლოდ მომავალი დიზაინისთვის, მიმდინარე კოდი ასე არ არის): თეთრი ფონი, პროფესიონალური მინიმალისტური SaaS. ფასების ბარათები, საბაზრო ღირებულებები და ავტომობილის გაყიდვის ინტერფეისი ამ პროდუქტში არ არის და დიზაინში არ უნდა გაჩნდეს. კვოტა, ლიმიტი და კაბინეტის მოხმარება რეალური ფუნქციაა და რჩება.

## 1. დანიშნულება და რეალური ფუნქციები

GeoAPI არის PHP 8.2+ ფრონტ-კონტროლერი Laravel-ის გარეშე. ერთადერთი Composer დამოკიდებულებაა `phpmailer/phpmailer`. წყარო: `composer.json`, `public/index.php`.

პროდუქტი სამი ფენაა:

1. კატალოგი: ბრენდი → მოდელი → დაჯგუფებული თაობა. მოდიფიკაციების სია და ერთი მოდიფიკაციის დეტალი ცალკე დროშებით ირთვება. წყარო: `src/Catalog/Http.php`, `src/Catalog/CatalogRepository.php`.
2. პლატფორმა: ანგარიში, პროექტი, საიდუმლო გასაღები, საჯარო ვიჯეტის გასაღები, კვოტა, ელფოსტა, ადმინის მიმოხილვა. სქემა `platform`. წყარო: `src/Platform/Http.php`, `migrations/`.
3. ჩასასმელი ფილტრი `<geoapi-filter>`: ბრენდი → მოდელი → წელი → ძარა. წყარო: `public/widget/v1/geoapi-filter.js`, `src/Widget/Http.php`.

საჯარო ენა ქართულია (`lang="ka"`). წყარო: `src/SiteChrome.php`.

`public/index.php`-ის ფაილის თავი კვლავ აღწერს imagin.studio-ს შემცვლელს და Wikimedia ფოტოებს. მოქმედი ფოტოს გზა, თუ `/getImage` იძახება, არის `src/DromResolver.php`. `src/WikimediaResolver.php` აპლიკაციის მარშრუტიდან არ იძახება. ეს აცდენა დოკუმენტაციისაა, არა კატალოგის API-ის.

რა არ არის პროდუქტი: VIN, სანომრე ნიშანი, განცხადება, დილერი, ფასი, გადახდა, გამოწერის ჩეკაუთი. ადმინის მენიუში გამოწერისა და გადახდის პუნქტები მხოლოდ გამორთული წარწერებია. წყარო: `src/Platform/View.php` (`adminNav`).

## 2. მარშრუტები, გვერდები და ნავიგაცია

რიგი `public/index.php`-ში:

1. `/widget/v1/…` (გარდა `.js` ფაილისა) → `Geoapi\Widget\Http`
2. `/api/v1…` → `Geoapi\Catalog\Http`
3. `/docs/{ფაილი}` → მხოლოდ ოთხი ნებადართული Markdown, `text/plain`
4. თუ `GEOAPI_PLATFORM_ENABLED` ჩართულია და გზა პლატფორმის სიაშია → `Geoapi\Platform\Http`
5. `/guide`, `/privacy`, `/terms`
6. თუ პლატფორმა გამორთულია: `/login`, `/register`, `/logout`, `/account`, `/auth/me` → `geoapi_closed()`
7. `/getImage`
8. `Geoapi\Auth\Router` — ამ ეტაპზე პრაქტიკულად მკვდარია, რადგან იგივე გზები უკვე ან პლატფორმამ აიღო, ან დაიხურა
9. `/` და `/docs` → ლენდინგი
10. სხვა HTML გზა → 404

სტატიკური ფაილები (`/assets/…`, `/widget/v1/geoapi-filter.js`) ვებ-სერვერი პირდაპირ გასცემს. ჩაშენებულ PHP სერვერზე `index.php` არსებულ ფაილს თვითონ არ ერევა.

### საჯარო ნავიგაცია

`src/SiteChrome.php`:

- ლოგო → `/`
- დემო → `/#demo`
- დოკუმენტაცია → `/guide`
- თემის ღილაკი (მუქი ნაგულისხმევი, ღია `localStorage` გასაღები `geoapi-theme`)
- სტუმარი, პლატფორმა ჩართულია: „შესვლა“, „ანგარიშის შექმნა“
- შესული მომხმარებელი: „კაბინეტი“, „ჩემი პროექტები“ — ორივე `/account`. ადმინის ბმული საჯარო ჰედერში არ არის
- პლატფორმა გამორთულია: ღილაკი „მალე გაიხსნება“, მოქმედების გარეშე
- მობილური (≤760px): ბურგერი ხსნის იმავე ბმულებს. „შესვლა“ და „კაბინეტი“ იმალება (`hide-m`)

ფუტერი: დოკუმენტაცია, შესვლა, რეგისტრაცია (მხოლოდ თუ პლატფორმა ჩართულია), წესები, კონფიდენციალურობა, `hello@geoapi.ge`. შესული მომხმარებლისთვისაც ფუტერი კვლავ შესვლა/რეგისტრაციას აჩვენებს — კაბინეტის ბმული ფუტერში არ არის.

| `/account` | GET, POST | პროექტების სია და შექმნა |
| `/account/projects/{id}` | GET, POST | პროექტის კაბინეტი |
| `/account/projects/{id}/playground` | GET | Playground |

შესვლის შემდეგ ადმინი მიდის `/admin`-ზე, დანარჩენი `/account`-ზე. რეგისტრაციის შემდეგ ყველა, ადმინის როლის გარეშე, მიდის `/account`-ზე. წყარო: `afterLogin`, `register`.

### დოკუმენტაციის ქვესექციები

`/guide` ერთი გვერდია. გვერდითი მენიუ ღუზებია, ცალკე მარშრუტი არა. წყარო: `geoapi_guide()`:

- `#start` საწყისი ინსტრუქცია
- `#auth` ავტორიზაცია და გასაღებები
- `#limits` ლიმიტები და შეცდომები
- `#widget` ვიჯეტის ჩასმა
- `#domains` დაშვებული დომენები
- `#event` მოვლენა `geoapi:change`
- `#cursor`, `#claude`, `#codex` AI ინსტრუქციის ჩასმა
- `#brands`, `#models`, `#generations`, `#modifications`, `#modification`, `#coverage`

მობილურზე გვერდითი მენიუ იმალება და ჩნდება ზოლი „დაწყება“. ძიება `data-doc-search` ფილტრავს გვერდითი ბმულების ტექსტს. წყარო: `public/assets/site.js`, `public/assets/site.css` (≤760px).

ნედლი Markdown, მხოლოდ ეს ოთხი ფაილი (`geoapi_resolve_doc`):

- `/docs/catalog_api.md`
- `/docs/projects_api_keys.md`
- `/docs/usage_and_limits.md`
- `/docs/widget_integration.md`

სხვა `docs/` ფაილი ამ გზით არ იხსნება. `/docs` ფაილის გარეშე ლენდინგია, დოკუმენტაცია არა.

## 3. გვერდები: სექციები, მონაცემები, მოქმედებები

### 3.1 ლენდინგი `/` და `/docs`

სტატუსი: მუშაობს. ფაილი: `public/index.php` (`geoapi_landing`), `public/assets/site.js`, `public/assets/site.css`.

სექციები:

- თარიღის ზოლი: `geoapi`, `API v1`, მიმდინარე თვე ქართულად
- H1 და მოკლე აღწერა
- ძირითადი მოწოდება: „უფასო ანგარიშის შექმნა“ → `/register`, ან „მალე გაიხსნება“ თუ პლატფორმა გამორთულია
- მეორე ღილაკი: „დოკუმენტაციის ნახვა“ → `/guide`
- დემო `#demo`: ოთხი საფეხური (ბრენდი, მოდელი, წელი, ძარა), ძიება, სია, JSON, ჯაჭვი, ჩასმის სკრიპტის კოპირება
- ბრენდების მოძრავი ზოლი (პირველი 16 სახელი)
- შენიშვნა რაოდენობებზე, თუ `PublicCounts` სტატუსი `ok`-ია

დემო იძახებს `POST /widget/v1/demo/…` და პროექტის კვოტას არ ხარჯავს. წყარო: `src/Widget/Demo.php`, `public/assets/site.js`.

მონაცემები დემოში: `id`, `name`, `slug` (ბრენდი), წლის `bodies`. არჩევანის JSON-შია `brand_id`, `model_id`, `year`, `body_type`. თაობა დემო ეძებს წელსა და ძარასთან შესატყვისად (`matchGeneration`), მაგრამ ვიჯეტის საჯარო მოვლენაში `generation_id` მაინც `null`-ია. წყარო: `public/widget/v1/geoapi-filter.js` (`emit`).

ცარიელი და შეცდომის ტექსტები დემოში: „მითითებული პირობებით ბრენდი/მოდელი ვერ მოიძებნა“, „ამ მოდელისთვის გამოშვების წლები ჯერ არ არის“, „კატალოგი დროებით მიუწვდომელია“.

ფასის, განცხადების ან გაყიდვის ბლოკი ამ გვერდზე არ არის.

### 3.2 404

სტატუსი: მუშაობს. ფაილი: `public/index.php`.

H1 „გვერდი ვერ მოიძებნა“, ტექსტი, ღილაკი „მთავარზე დაბრუნება“. ჰედერი და ფუტერი საჯაროა.

პლატფორმის `Http::notFound` და `methodNotAllowed` HTML-ს არ ხატავს. პასუხია JSON: `{"ok":false,"error":"not_found"}` ან `method_not_allowed`, სტატუსით 404 და 405. წყარო: `src/Platform/Http.php`. დიზაინის ეკრანი მხოლოდ საჯარო 404-ია.

### 3.3 `/guide`

სტატუსი: მუშაობს. ერთი გრძელი სტატია.

## 8. API, მოდელები, სცენარები

### 8.1 სერვერული კატალოგი

ავტორიზაცია: `Authorization: Bearer geoapi_sk_…`. `?apiKey=` და `X-API-Key` არ იკითხება. წყარო: `src/Catalog/Access.php`, `src/Platform/ApiKeys.php`.

| მეთოდი და გზა | სტატუსი | პასუხის ველები |
|---|---|---|
| `GET /api/v1/brands` | მუშაობს | `id`, `slug`, `name`, `synonyms`, `is_lcv_or_commercial`, `logo_url_light`, `logo_url_dark` |
| `GET /api/v1/brands/{slug}/models` | მუშაობს | `id`, `brand_id`, `slug`, `name`, `markets`, `generations_count` |
| `GET /api/v1/models/{id}/generations` | მუშაობს | `id`, `model_id`, `slug`, `name`, `year_start`, `year_end`, `period_text`, `body_type`, `chassis_code`, `steering_wheel`, `market` (ყოველთვის null), `display_label` |
| `GET /api/v1/generations/{id}/modifications` | ნაწილობრივ მუშაობს | `id`, `generation_id`, `name`, `engine_volume_cc`, `transmission`, `year_start`, `year_end`. დროშა `GEOAPI_MODIFICATIONS_ENABLED` |
| `GET /api/v1/modifications/{id}` | ნაწილობრივ მუშაობს | ზემოთ ჩამოთვლილი პლუს `drive_type`, `body_type`, `brand`, `model`, `generation`. დროშა `GEOAPI_MODIFICATION_DETAILS_ENABLED` |
| `GET /api/v1/coverage` | მუშაობს | რვა რიცხვი და `measured_at`, `data` კონვერტის გარეშე |

სიის კონვერტი: `{ data, meta:{ page, per_page, total } }`. `page` 1…1000000, `per_page` 1…100, ნაგულისხმევი 50. კურსორი არ არის.

შეცდომა: `{ error:{ code, message } }`. კოდები: `unauthorized` 401, `forbidden` 403, `not_found` 404, `method_not_allowed` 405, `invalid_parameter` 422, `RATE_LIMIT_EXCEEDED` და `MONTHLY_QUOTA_EXCEEDED` 429, `unavailable` 503.

წარმატებულ პასუხზეა `X-Quota-Limit`, `X-Quota-Remaining`, `X-Quota-Reset`. 401 კვოტას არ აჩვენებს.

თაობის საჯარო `id` ჯგუფის მინიმალური `generations.id`-ია. მეზობელი რიგის id მოდიფიკაციების გზაზე 404-ია. წყარო: `CatalogRepository::modifications`.

ლოგოს ველები ბრუნდება. ვიჯეტი მათ არ ხატავს. ცოცხალი ლოგოს შევსება: უცნობია.

`photos` და `generations.photo_urls` მხოლოდ coverage-ის რიცხვშია. სიის პასუხში ფოტო არ გადის.

### 8.2 ვიჯეტის API

POST, არა GET. გასაღები გზაშია: `geoapi_pk_` + 32 hex. სხეული JSON `page`, `per_page`.

| გზა | სტატუსი |
|---|---|
| `POST /widget/v1/{pk}/brands` | მუშაობს |
| `POST /widget/v1/{pk}/brands/{slug}/models` | მუშაობს |
| `POST /widget/v1/{pk}/models/{id}/years` | მუშაობს. წლები სერვერულ GET-ზე არ არის |
| `POST /widget/v1/{pk}/models/{id}/generations` | მუშაობს |
| იგივე ოთხი `/widget/v1/demo/…` | მუშაობს, same-origin, 120 მოთხოვნა წუთში IP-ზე, პროექტის კვოტის გარეშე |

წლის ელემენტი: `id`, `name`, `bodies` (სტრიქონების სია).

მოვლენა `geoapi:change`: `brand_id`, `model_id`, `year`, `body_type`, `generation_id` null, `modification_id` null, და შესაბამისი `*_name`.

### 8.3 Playground-ის შიდა API

## DESIGN HANDOFF SUMMARY

პროდუქტი დეველოპერის SaaS-ია: კატალოგის API, პროექტის გასაღები, კვოტა და ჩასასმელი არჩევანი. ავტომობილის მაღაზია, განცხადება და ფასი არ დახატო.

ვიზუალი, რომელიც მომავალმა დიზაინმა უნდა დაიცვას: თეთრი ფონი, მინიმალური პროფესიონალური SaaS, ქართული ინტერფეისი, არსებული ტექსტები. მუქი თემა დღეს ნაგულისხმევია (`site.css`, `site.js`). ახალი მიმართულება მას ცვლის მხოლოდ დიზაინის ფაზაში. კოდი ამ დოკუმენტით არ შეცვლილა.

შეინარჩუნე რეალური ფუნქციები: რეგისტრაცია და შესვლა, ელფოსტა, პროექტი, ორი ტიპის გასაღები, origin, ჩასმა, preview, მოხმარების 30 დღე, Playground, Explorer, ვიჯეტის ოთხი საფეხური, ადმინის მიმოხილვის რიცხვები. ლიმიტი 60 და 10 000 ტექსტად რჩება. ეს ფასის ბარათი არ არის.

არ დაამატო: საბაზრო ღირებულება, განცხადების ბადე, VIN-ის ფორმა, ტარიფის შედარება, გადახდის ფორმა. ადმინის მენიუს გამორთული პუნქტები დატოვე როგორც ჯერ არარსებული, სანამ მათი ველები კოდში არ გაჩნდება.
